# 王氏手工皮艺 · 品牌官网

> 长春 · 高新区 · 学府街 × 博文路 · 栖乐荟购物中心 5F
> 百年皮艺 · 非遗手作

一套纯静态的品牌展示站，参考国际皮具品牌（Hermès / Delvaux / Bottega Veneta / Loewe / Polène 等）的叙事结构：
大图开场 → 品牌理念 → 作品 → 工艺 → 到店。全部页面共用一套设计系统，不依赖任何第三方框架、字体或 CDN，离线可直接打开。

---

## 1. 页面结构

| 文件 | 内容 | 对应国际品牌的做法 |
| --- | --- | --- |
| `index.html` | 首页：主视觉、品牌宣言、三条理念、精选作品、四道工序、皮料、到店引导 | Maison 首页 |
| `story.html` | 品牌故事：传承脉络、非遗、时间轴、「三个不」 | Maison / Heritage |

| `visit.html` | 到店：地址、营业时间、位置示意图、联系方式、到店可做 | Boutique |

公共资源：

```
assets/css/main.css      设计系统与全部样式
assets/js/main.js        交互（滚动吸顶、抽屉菜单、入场动画、作品筛选、表单）
assets/img/              中英文站点图片（全部程序化生成，见第 5 节）

assets/render_products.py 产品实物渲染器（7 款统一机位/灯光）
```

## 2. 本地预览

直接双击 `index.html` 即可在浏览器打开（无跨域限制，纯静态）。

如需模拟线上环境（推荐，手机同局域网访问）：

```powershell
cd site
python -m http.server 8080
# 浏览器访问 http://127.0.0.1:8080
```

手机预览：电脑与手机连同一 Wi-Fi，手机访问 `http://<电脑局域网IP>:8080`。

## 3. 上线前必须替换的信息（重要）

站内联系方式目前是「到店咨询」的占位表述，请按实际情况补齐：

1. **电话 / 微信**：`visit.html` 中「Phone / WeChat」卡片、`works.html` 表单说明、页脚 Contact 栏。
2. **微信二维码**：放一张 `assets/img/wechat-qr.png`，把 `visit.html` / `works.html` 里的 `.qr` 占位块替换为
   `<img src="assets/img/wechat-qr.png" alt="店主微信二维码" style="width:132px;height:132px">`。
3. **营业时间**：现为 10:00 — 21:00（随商场），如与实际情况不同，请全局替换。
4. **表单接收**：当前为纯前端演示——提交后只生成可复制的预约信息，不会自动发送。
   若要真正收集预约，二选一：
   - 换成第三方表单服务（金数据、问卷星、飞书表单）的嵌入链接；
   - 或把 `assets/js/main.js` 里的表单提交改为 `fetch` 到自建接口。
5. **ICP 备案号 / 公安备案**：如使用国内服务器与域名，请在页脚加备案号并链接到 beian.miit.gov.cn。
6. **公众号 / 小红书**：如有，可在页脚 Contact 栏补充入口。

## 5. 图片素材说明

站内所有图片均为 **本仓库脚本程序化生成**，无第三方版权图片，可商用：

| 文件 | 用途 | 生成方式 |
| --- | --- | --- |
| `leather-dark.jpg` | 深色皮革（首页主视觉、深色区块背景） | 分形噪声 + 皮革颗粒 + 打光 |
| `leather-caramel / oxblood / olive.jpg` | 三种皮样（工艺页材料卡） | 同上，换色 |
| `paper.jpg` | 米色纸纹（作品卡片底） | 噪声 + 纤维 |
| `grain.jpg` | 颗粒叠加层 | 灰度噪声，CSS `overlay` 混合 |
| `swatches.jpg` | 皮样平铺（品牌页横幅、首页皮料区） | 多张皮样旋转叠放 + 投影 |
| `works/*.webp` | 7 个款式的产品实物渲染图（托特、斜挎、钱夹、卡包、皮带、手账本、钥匙包），1000×1000 透明背景 | `assets/render_products.py` 程序化「棚拍」渲染：SDF 高度场（厚度/倒角/叠层）→ 法线光照 + 高光 → 皮革颗粒 / 车缝线迹 / 烫印 → 统一取景与投影 |
| `map.svg` | 栖乐荟位置示意图 | 手绘示意图（非精确地图） |

**替换为实拍照片**：把 `assets/img/works/*.webp` 换成同名的产品照片即可（建议 1000×1000、正方形、透明或浅色背景，产品占画面约 76%，七张保持同一机位与光位）。
现有图片为**程序化渲染**（统一顶光、皮革颗粒、车缝与五金细节），不是实拍照片；有实拍图时优先用实拍，一致性更容易保证。

重新生成纹理（可选）：

```powershell
python assets/gen_textures.py
python assets/gen_scenes.py
```

## 6. 部署建议

- **静态托管**：阿里云 OSS / 腾讯云 COS / Vercel / Netlify / Cloudflare Pages 均可，直接上传 `site/` 全部文件。
- **国内访问**：如需绑定域名并稳定访问，建议国内服务器 + 域名备案；纯展示站一个 1 核 1G 的轻量服务器足够。
- **微信内打开**：本站无外部资源依赖，微信内置浏览器可直接打开；表单与二维码建议引导到微信沟通。
- **SEO**：`index.html` 已内置 LocalBusiness 结构化数据（店名、地址、营业时间），上线后可在百度地图 / 高德地图同步商户信息。

## 7. 设计说明（给店主看）

- **配色**：深棕皮革（#3d2517）+ 米纸（#f4eee2）+ 黄铜（#b4915c），接近老皮具工作台的颜色。
- **字体**：中文用宋体（标题）+ 苹方/微软雅黑（正文），英文用 Georgia；不加载网络字体，打开即显示。
- **版式**：大量留白、细线分隔、大写英文小标签、编号（01 / 02），是国际皮具品牌常用的「档案感」排版。
- **动效**：滚动入场、主视觉视差、作品筛选、移动端抽屉菜单；尊重系统「减少动态效果」设置。
- **响应式**：桌面 1440 / 平板 900 / 手机 500 以下三档，手机端已单独调过字号与间距。
